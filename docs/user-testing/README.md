# User testing (CP2)

Two or more sessions with people **outside the team**. Each session has its own record file; this page is the summary. Record what participants actually did and said. Do not fill in results that did not happen.

## Rules

- Participants are real people outside the team who agreed to take part. Use codes (P1, P2, ...); no real names or contact details.
- Two-person interaction: one participant plays the newcomer, the other plays the mentor (or one person plays both in two browser tabs; say which in the record).
- Write down behaviour (where they got stuck, how long it took, what they asked), not only opinions.
- Every important finding gets a follow-up: an issue, a PR, or a DECISION.md entry that names the session as its source.
- If something was not done (for example only one session, or placeholder AI instead of a real model), say so in "Gaps" below.
